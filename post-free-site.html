How this site runs for free

There's no framework. Every page is a plain HTML file, one stylesheet does the old-school black-and-white look, and one small script adds the menu, the sidebar and a couple of tricks.

Hosting

The files live in a GitHub repository, and GitHub Pages serves them for free at a github.io address. A static site has nothing to run, so there's nothing to pay for or patch.

Guestbook

A static site can't store messages itself. The guestbook uses giscus, which keeps comments as GitHub Discussions on the same repo. Visitors sign in with GitHub.

The catch

No server code and no database of my own. For a personal site that's a fine trade.
